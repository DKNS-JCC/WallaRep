WallaRep

Pega el enlace de un anuncio de Wallapop y muestra los datos públicos del vendedor, incluidos algunos que Wallapop no enseña en su propia app.

WallaRep es una herramienta independiente, no oficial y sin afiliación con Wallapop S.L. Los datos se piden en directo a la API pública de Wallapop cada vez que consultas un anuncio: no se guardan, ni se registran, ni se comparten con nadie. Esta página no emite ninguna opinión sobre la fiabilidad de ningún vendedor — se limita a mostrar los números tal cual los ofrece Wallapop; sé tú quien los interprete. Los datos pueden estar incompletos, dejar de funcionar o cambiar sin aviso, ya que dependen de una API interna no documentada por Wallapop.
